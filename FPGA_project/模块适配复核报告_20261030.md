# 板载10kΩ DS18B20模块适配复核

审查发现：硬件接口配置与用户给出的模块相符，原说明对裸探头和成品模块的区分不足；原协议仿真使用理想上拉，未覆盖这块模块的有限上升时间。本次完善说明与验证，不修改通过签核的功能RTL或固件。

## 逐项结果

| 项目 | 结论 |
|---|---|
| 板载电阻 | 图1原理图与图2的R1=103相符，为DQ–VCC的10kΩ上拉；R2=102是LED限流。无需额外电阻。 |
| 供电与引脚 | 模块VCC→B J2-29 3.3V，GND→J2-30，DO/DQ→J2-37/N12。两侧插针/焊孔顺序相反，按丝印接。 |
| FPGA IO | N12/LVCMOS33/PULLTYPE NONE，DQ只拉低或高阻。配置适合已有板载上拉，无需启用内部上拉或改为推挽。 |
| 数据线语义 | DO是单总线双向数据；FPGA需发送复位、配置、转换及读取命令，不能当温度报警的高低电平脚。 |
| 时序 | 复位低500µs、读低2µs、写1低5µs、写0低65µs、时隙75µs；转换760ms，完整CRC及配置/范围资格保留。 |
| 分辨率 | 12位对应0.0625℃步进。4位小数用于精确表示这个步进，不表示0.0001℃测量准确度。 |
| 告警 | FPGA执行45/55/50℃及连续3样本策略。器件TH/TL回读用于配置资格，不是本工程的55℃告警来源；不使用Alarm Search或Copy Scratchpad写EEPROM。 |
| 故障及控制 | 沿用故障保锁、合格降温人工解锁、独立STOP、A本地优先及原串口事务机制。无需因这块模块改动。 |

官方时序依据：[ADI DS18B20数据手册](https://www.analog.com/media/en/technical-documentation/data-sheets/ds18b20.pdf)，表格及1-Wire时序章节。商品图仅作为本款模块电阻/接口的依据，未把图3的多探头、寄生供电描述当成当前固件能力。

## 新增模型验证

R=10kΩ，总线电容假设25/100/220/470pF，按指数RC上升至80%电源（假设门限2.64V）建模；对应延时403/1610/3541/7565ns。该门限是选取的保守测试条件，不是实测FPGA门限或实际线缆电容。

四种电容均在1MHz参数下完整运行760ms转换、正温25.0625℃、负温−10.125℃、45℃、CRC拒绝、断开和恢复；另以生产25MHz参数复测470pF。设备数据最迟14.9µs才拉低、存在脉冲延迟取60µs，五组全部通过。模型仅提供延迟弱上拉和理想低电平，不是SPICE或电气验收；不推导保证线长、真实温度精度或长稳结论。

新增模型独立观察总线边沿，RC网络读取两个公开开漏驱动状态；没有读取DUT状态机/计数器来产生响应。模型明确区分从机释放的慢上升沿与后续主机复位，复位期间允许上拉先稳定。
