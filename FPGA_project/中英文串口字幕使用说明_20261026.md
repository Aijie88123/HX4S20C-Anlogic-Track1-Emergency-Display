# 中英文串口字幕使用说明（2026-10-26）

本完整包为用户2026-10-26明确选定的唯一最佳uart_subtitle_fixed_20261026，已合入电脑工具GUI修复；原follow_view成为历史最佳，全部旧工程/RAR保留，未合入map_flow。

## 烧录与连接

**本次必须同时 PROGRAM_FLASH 本包 firmware/A_display_3V3.bit 与 B_control_3V3.bit。** 新增A字幕接收/显示，不能沿用父版“只刷B”的方法。固件哈希见验证报告。

TF仍A，原图片/音乐不改，A板HDMI直连显示器，两板网络保持。烧录后两板完全断电约5秒再一起上电；USB串口线可能供电，断电时须一并拔除。等原启动加载完成、两板联机再发送。

电脑数据线接B板板载CH340串口USB口，使用与实际接口匹配的数据线，不另接TX/RX杜邦线，不要误接USB-JTAG口。仍为F12 FPGA RX、D12 FPGA TX，115200、8N1、无流控。

## 发送正文

1. 解压完整工程，关闭占用相同COM口的串口助手。
2. 双击根目录“启动字幕工具.cmd”。它使用Windows自带PowerShell5.1、WinForms及System.Drawing，无需Python；不支持直接改用PowerShell7。
3. 刷新端口，选择B板CH340对应COM。
4. 输入正文，例如：`紧急通知：请按绿色路线有序疏散 EXIT A`。
5. 点预览，再点“发送字幕”。进度到128块后还需等A板帧边界提交的返回确认。
6. 正常播放时在底部滚动；应急地图就绪后在底部信息区上方滚动。启动加载页和报警引导页保留原显示门控。
7. 点“清除自定义字幕”，A在帧边界关闭新字幕，恢复原欢迎字幕/地图界面。

**直接输入正文，不加TEXT前缀。** 电脑转字模，B板经原网络送A显示；普通串口助手直接发送UTF-8中文不会自动生成字幕，请用配套工具。

原PING、STATUS?、DEMO FIRE/QUAKE/LAB/DRILL/STOP、BARRIER SET 0..3、LOG READ/CLEAR保留。字幕正文不会自动触发应急事件。使用串口助手前等本工具发送结束，避免抢占同一COM；工具每次发送后会释放端口。DS18B20尚未接入，TEMP?仍报未装传感器。

## 限额与保护

字模16像素高、最多1024像素宽，按16对齐；显示放大2倍为32像素高白色像素字。通常约64个中文，实际由字形宽度决定，中英混排可用。只收单行，超长报错、不静默截断；特殊生僻字取决于电脑字体，请看预览。板上不增加处理器或完整中文字库。

两库各2048字节，新字幕完整接收且全图CRC一致后，在实际VS切换。发送中断不会显示半条；最后完整字幕可继续滚动。A复位/断电丢失，电脑需重发，不写TF，原事件日志不记录字幕正文。

超时可能发生在提交后丢确认，**请目视确认后重发**。成功回包表示内部VS提交，仍不等价于物理HDMI验收。必须使用配套新A/B。拔USB若同时切断B供电，原双板重启限制仍适用。

## 命令行

使用Windows PowerShell5.1：

```powershell
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\tools\subtitle_sender.ps1 -Port COM5 -Text "请沿绿色路线疏散 EXIT A"
powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File .\tools\subtitle_sender.ps1 -Port COM5 -Clear
```

不接串口只生成预览：

```powershell
powershell.exe -NoProfile -STA -File .\tools\subtitle_sender.ps1 -RenderOnly -Text "应急演练 EXIT B" -OutputPrefix D:\caption_preview
```

生成.bin、.png、.uart和.json，.uart为二进制，不作为文本粘贴到串口助手。
