## 参数入口

- [map_scene_presets.json](D:/HX4S20C_resource_timing_20261025/assets/map_scene_presets.json)：集中维护名称、事件、自动出口及实时路障策略。

- [resolve_map_scene.py](D:/HX4S20C_resource_timing_20261025/tools/resolve_map_scene.py)：程序入口 `resolve(name, barrier_mode)`，返回原控制接口接受的字段及明确的出口/路障策略；命令行也可查询。
- [generate_map_scene_parameters.py](D:/HX4S20C_resource_timing_20261025/tools/generate_map_scene_parameters.py)：生成规范字典，`--check`检查是否与源配置一致。本版只接受用户确认的自动全部出口/实时路障方案，不把硬件尚不支持的固定出口配置静默忽略。

```powershell
python tools/resolve_map_scene.py B --barrier-mode 2
python tools/generate_map_scene_parameters.py --check
```

前一命令输出B、地震/event1、actual_state3、自动候选[9,10,11,12]和实时路障2。非法名称、大小写不符或越界路障报错。该查询不自动向板卡发送控制包，板上继续使用原事件/路障控制；需要名称的场景选择端可调用此接口形成规范参数。配置名不作为新字段塞进V12或像素路径，显示层文字和素材保持。
