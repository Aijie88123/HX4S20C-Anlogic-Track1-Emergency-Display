# 3至4分钟介绍词与操作顺序（串口最后）

顺序：基础播放 → 画面增强 → 应急模式 → 温度传感器 → 串口信息发布 → 总结。先完成上电、读卡、接屏和串口连接，再开始讲解计时。

|环节|3分钟版|4分钟版|核心操作|
|---|---|---|---|
|基础播放|0:00–0:25|0:00–0:30|手动切图、自动轮播并确认声音|
|画面增强|0:25–0:55|0:30–1:10|代表转场、粒子进出、参数与可视化|
|应急寻路|0:55–1:40|1:10–2:10|手动火灾、实际状态确认、路障重规划|
|温度自动联动|1:40–2:15|2:10–3:00|实时测温；有条件展示真实温度触发|
|串口信息发布|2:15–2:40|3:00–3:35|最后发布中英文字幕，展示状态与日志|
|收束与亮点|2:40–3:00|3:35–4:00|概括创新点，结束演示|

开场：各位老师好，下面介绍我们的基于安路FPGA的HDMI多媒体展示与校园应急引导系统。


## 1. 基础播放

> 系统基于HX4S20C双板FPGA。通过SPI读取TF卡中的24位BMP，解析后写入SDRAM，再由HDMI稳定输出；支持手动切图、3/5/8秒轮播、暂停和48kHz音频输出。

**操作：** 指向HDMI画面；按一次切图，再展示自动轮播。声音提前打开，用一句话说明音视频同时输出。

**观察：** 观察图片连续显示与声音。上电、读卡和串口准备在讲解计时前完成。


## 2. 画面增强

> 在基础播放上，系统加入平滑转场、图片缩放适配、实时亮度与对比度调节、文字叠加、音源选择和音频可视化。粒子场景进出也具有过渡效果。

**操作：** 用原有拨码/按键展示翻牌或缩放；切入、切出粒子画面；再调整一次亮度或对比度，指向音频可视化。

**观察：** 只演示一组代表效果，其他效果口述覆盖，减少重复拨码。


## 3. 应急寻路

> 系统将多媒体展示与校园应急引导结合，支持四类事件、立体地图、建筑中文名称、最短可达路径、三档地图缩放和持续跟随镜头。增加路障后可重新规划出口与路线。

**操作：** 点击“手动火灾演示”；等待实际事件和出口确认，再点“增加封路”，展示路线变化。演示后，在未温度锁存时请求恢复轮播并确认，再介绍温度。

**观察：** 推荐出口必须等新状态确认；无路时如实显示暂无可用路线。地震、实验室事故和演练用一句话说明。


## 4. 温度自动联动

> DS18B20实时测温并叠加到HDMI左上角。45℃预警，一次有效采样达到55℃即锁存并请求火灾预案，板端工作不依赖电脑。故障不会清除已有报警。

**操作：** 接好探头后展示实时读数；达到真实阈值时观察自动告警。降到50℃及以下并满足三次有效采样后，先人工解除温度锁存，再独立请求恢复轮播，确认正常后再演示串口自定义字幕。

**观察：** 升温和降温需要实际时间；三分钟版可展示读数并说明阈值。手动火灾按钮始终标明人工演示。


## 5. 串口信息发布

> 最后，电脑通过B板USB串口发送中英文正文。FPGA完成完整字模校验后，在帧边界更新HDMI滚动字幕，同时返回状态与事件记录；控制台还支持日志导出与串口自动恢复。

**操作：** 确认已恢复正常且无温度锁存后，点击右侧“发布本段HDMI字幕”，指向HDMI字幕，再指出上方连接与实际状态。

**观察：** 若温度告警尚未解除，展示串口状态、日志和自动应急字幕，不覆盖告警。


## 6. 收束与亮点

> 我们的创新在于将展示、环境感知、自动应急、动态疏散和电脑信息发布整合为以太网双板协作的纯FPGA系统，并通过状态确认、故障保锁和串口恢复提升演示可靠性。

**操作：** 概括展示、感知、应急、引导与信息发布的闭环，结束演示。

**观察：** 突出一条闭环：正常展示 → 事件触发 → 地图引导 → 路障重规划 → 状态记录。


结束：以上就是我们的系统演示，谢谢各位老师。

## 应急、温度与串口之间的衔接

人工应急与路障演示后，若无温度锁存，先请求恢复轮播并确认实际正常，再介绍温度传感器。温度达到55℃真实触发时，必须降到50℃及以下并满足连续3次有效读数、人工解除温度锁存，再独立请求恢复轮播；确认正常后再发布自定义串口字幕。

若仍处于温度告警，就在最后的串口部分展示实时状态回传、事件日志和自动应急字幕，普通字幕不能覆盖告警。手动火灾明确属于人工演示，不当作传感器自动触发。

3分钟/4分钟是讲解预算，真实升降温与链路等待须提前实测。三分钟版可展示温度读数并说明阈值；完整热触发和冷却另留时间。CSV导出可预先准备，避免现场保存对话框占用讲解时间。
