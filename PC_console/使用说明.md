# 串口自恢复控制台（2026-10-31）

这是 temperature_single_20261031 最佳工程的独立电脑软件更新。直接使用现有配套A/B固件，无需重新烧录。原最佳工程、RAR及选择记录保持原样。

## 使用

1. 关闭旧控制台和串口助手，避免同一COM被占用。
2. 双击“启动串口自恢复控制台.cmd”。Windows请求管理员权限时允许：CH340设备重启需要该权限。取消提权也会打开普通模式，可正常连接；设备代码10时需点击“管理员修复”。
3. 保持“自动连接 / 断线重连”勾选。软件可以先开，随后接B板USB数据线并上电；一般每2秒枚举一次。首次仅有一个CH340时自动选择，成功后记住设备实例，支持同一实例COM号改变。
4. 多个CH340且尚未记住B板时，手动选择正确端口再点“连接”。记住的设备缺席时不会改连另一块板。
5. 主动点击“断开”会取消自动连接。重新勾选自动连接可恢复。关闭窗口会释放串口，不向板子发送STOP或清字幕。

“启动应急管理控制台.cmd”为普通权限入口，也包含新的自动发现、重连和修复按钮。两个入口应只开一个窗口。

## 自动恢复范围

- 后台枚举CH340及当前COM，保持界面响应；端口列表变化不随意重置用户选择。
- 无串口时持续等待，不把未插USB、多个适配器、端口占用、驱动故障混成同一提示。
- 对已识别B板CH340的设备代码10，空闲时定向执行一次设备重启并等待重新枚举。自动重启间隔至少30秒，每个设备每次软件运行最多2次；失败后可手动修复。系统仍可能要求拔插USB或处理驱动。
- 仅重启精确的 USB\VID_1A86&PID_7523 设备实例，不卸载驱动，不重启电脑，不重置其他USB设备。正常占用或访问拒绝不会触发自动设备重启；手动修复正常设备前也检查串口独占访问。
- 连接失败后按2/4/8/15秒退避重试。必须等旧串口线程退出并释放后才开新会话，重新核验PING及完整STATUS。
- 旧会话排队的事件、TEMP CLEAR、路障、手动字幕等操作不会重放；失去回复的操作须根据新状态核对。原自动联动字幕选项保留，重连后按新读到的实际状态重新评估。
- 原温度卡、人工解锁、应急/封路、字幕及日志导出保持。电脑审计记录在本次软件运行内跨重连保留；重启软件后为新记录会话。
- 设备偏好存于 %LOCALAPPDATA%/HX4S20CConsole/connection.json，管理员修复结果存于同目录last-repair.json。
